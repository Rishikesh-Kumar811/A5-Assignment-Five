## ✨ Key Features

<br/>

### 1. 🎯 Dynamic Client Logo Cloud & Partner Marquee
- **Vector Brand Integration**: High-fidelity SVG client logos aligned in an adaptive responsive grid.
- **Adaptive Opacity & Filters**: Subtle greyscale-to-color hover transitions demonstrating high-level polish.
- **Trust-Building Layout**: Positioned prominently below the hero fold to maximize conversion credibility.

### 2. 👥 Interactive Creative Team Showcase & Role Matrix
- **Detailed Team Profiles**: Responsive cards showcasing agency leaders, specialists, and disciplines.
- **Micro-Interactions**: Smooth hover zoom, bio reveal transitions, and linked social interaction anchors.
- **Balanced Proportions**: Fluid card dimensions maintaining visual alignment across all screen widths.

### 3. 💼 High-Impact Portfolio Case Studies & Deliverable Previews
- **Rich Deliverable Cards**: Multi-column project showcases with category tags, descriptions, and thumbnail previews.
- **Multi-Device Adaptability**: Automatic column reflow from single-column mobile view to expansive multi-column desktop grids.
- **Accessible Anchor Triggers**: Keyboard-focusable action buttons for direct project exploration.

### 4. 🎨 Enterprise-Grade 94KB Custom CSS Architecture
- **Organized Token System**: Systematic color palettes, spacing variables, and modular typography scales.
- **Refined Micro-Interactions**: Custom cubic-bezier transition timing curves across interactive elements.
- **Ultra-Wide Desktop Locking**: Proportions locked cleanly on 2K, 4K, and 8K displays without stretching or content overflow.

## 🚀 Quick Start & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/Rishikesh-Kumar811/A5-Assignment-Five.git
cd A5-Assignment-Five
```

### 2. Launch with Live Server
Open `index.html` directly in any web browser, or launch via local server:

```bash
npx serve .
```

Visit `http://localhost:3000` in your web browser.
